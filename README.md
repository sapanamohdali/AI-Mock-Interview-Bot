
# 🤖 AI-Powered Mock Interview Bot

An AI-powered voice-based mock interview platform designed to help students improve their interview skills, build confidence, and prepare for job interviews.

## 📌 Project Overview

The AI Mock Interview Bot provides an interactive interview practice experience. Users can select an interview topic or upload their resume to practise answering interview questions.

The system uses speech recognition and AI-based evaluation to analyse responses and provide performance feedback.

## ✨ Key Features

- Topic-based interview practice.
- Resume-based interview questions.
- Voice-based answer recording.
- Speech-to-text conversion.
- Automated interview evaluation.
- Performance summaries and feedback.
- Identification of strengths and areas for improvement.

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini API
- OpenAI Whisper
- Speech Recognition
- Natural Language Processing

## 🎯 Objectives

- Help students prepare for technical and HR interviews.
- Improve communication and answering skills.
- Reduce interview anxiety.
- Provide personalised feedback.
- Make interview preparation more accessible.

## 🚀 Future Enhancements

- Multiple interview difficulty levels.
- Interview performance analytics.
- Improved adaptive questioning.
- Additional career-specific interview categories.
